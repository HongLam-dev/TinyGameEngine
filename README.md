# TinyGameEngine

A lightweight 2D game engine built from scratch in C++.

> This project is currently under active development.

TinyGameEngine is a personal hobby project focused on learning game engine architecture and modern C++ by implementing core engine systems from scratch.

The long-term goal is to use the engine to build a complete 2D platformer.

## Features

- Game loop
- Fixed timestep
- Input system
- Component-based architecture
- Sprite rendering
- AABB collision detection
- Basic collision resolution
- Rigidbody
- Collider debug visualization

## Tech Stack

- C++
- SFML
- CMake
- vcpkg
- Visual Studio
